# Medhaneeka Healthcare Private Limited website

This repository contains the custom WordPress theme used for the Medhaneeka Healthcare website and its separate Games page.

- [WordPress theme source](wordpress-theme/medhaneeka-company/)
- [Installable theme ZIP](releases/Medhaneeka_WordPress_Theme_v1.zip)

## Installation

In WordPress, go to **Appearance → Themes → Add New → Upload Theme**, choose the ZIP in `releases/`, install, and activate it. Create and publish a blank page titled **Games** with slug `games`; the theme supplies that page's layout. Use **Settings → Permalinks → Post name** so the page appears at `/games/`.

The homepage is provided by `front-page.php` and does not require a page builder. See the theme's `README.txt` for additional notes. The editable source and ZIP are the same version; when changing source, rebuild the ZIP before uploading the revised theme.
